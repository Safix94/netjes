# Netjes

Netjes ruimt je Downloads-map op. Gratis Windows-app van Agentiek.

- Sorteert je bestanden in nette mappen, met een animatie die je ziet gebeuren.
- Verwijdert of overschrijft niets, en je kan alles ongedaan maken.
- Download: https://www.agentiek.be/netjes (Windows 10 of 11, 64 bit).
- Zelf bouwen: installeer Node 22, pnpm en Rust, en run `pnpm install` en `pnpm tauri dev`.
- Tests: `pnpm test` en `cargo test --manifest-path src-tauri/Cargo.toml`.
- Licentie: MIT.
